# Overview dei file

- `index.html` — entry HTML di Vite (monta `src/main.tsx`).
- `src/App.tsx` — stato globale (tema, preferiti, nomi personalizzati) e collegamento tra landing e modale.
- `src/Landing.tsx` — landing page: header, ricerca, selettore stile, categorie, schede, footer.
- `src/ToolModal.tsx` — modale che ospita lo strumento aperto e fornisce i token di stile.
- `src/theme.ts` — classi dei tre stili della landing (artistic, immersive, sophisticated) e categorie.
- `src/tools/registry.ts` — elenco degli strumenti (nome, categoria, componente caricato in lazy).
- `src/components/` — un file per strumento, tutti costruiti con il kit in `src/ui/`.
- `src/ui/tokens.ts` — token di stile per tema (colori, font, bordi) usati dagli strumenti.
- `src/ui/kit.tsx` — componenti condivisi: campi, bottoni, slider, pannelli, risultati, avvisi.
- `src/ui/ColorWheel.tsx` — ruota dei colori (trascinabile con mouse o frecce, oppure solo di sola lettura) e nomi delle armonie.
- `src/components/CodeGenerator.tsx` — Generatore Codici: scheda QR code o codice a barre (`QrGenerator`, `BarcodeGenerator`).
- `src/components/MeasureConverters.tsx` — Valute e Unità: schede `CurrencyConverter` e `UnitConverter`.
- `src/ui/ShapePreview.tsx` — disegno animato della forma scelta in Geometria.
- `src/components/GeometryCalculator.tsx` — Geometria: forme 2D e 3D (perimetro, area, superficie, volume), calcoli in `src/lib/geometry.ts`.
- `src/components/ImageTools.tsx` — strumento Immagini: schede Converti, Ridimensiona, Ingrandisci (`ImageConverter`, `ImageResizer`, `ImageUpscaler`) con un'unica immagine caricata.
- `src/components/HandwritingFont.tsx` — Scrittura a mano in font: foglio PNG da stampare, lettura della foto e download del .ttf (usa `opentype.js`; logica in `src/lib/handwriting.ts`).
- `src/ui/ImageDrop.tsx` — caricamento di un'immagine (trascina o scegli) e hook `useImageSource`, usati dagli strumenti per immagini.
- `src/lib/` — logica pura degli strumenti: `markdown.ts`, `codiceFiscale.ts`, `calcEngine.ts`, `calcState.ts`, `marketData.ts`, `color.ts` (conversioni e armonie), `palette.ts` (colori dominanti), `imageOps.ts` (ricampionamento, nitidezza, filtri), `imageEncoders.ts` (BMP, TIFF, ICO), `barcode.ts` (Code 128, EAN-13), `pattern.ts` (pattern SVG), `handwriting.ts` (foglio e contorni dei glifi per il font a mano), `bracket.ts` (tabellone a eliminazione), `timeInput.ts` (tempo scritto a mano nel timer), `passwordModes.ts` e `wordlist.ts` (frasi, pronunciabili, PIN, token). Ogni modulo con logica ha il suo `*.test.ts` (`npm test`).
- `src/index.css`, `src/main.tsx`, `src/vite-env.d.ts` — stili globali, entry React, tipi Vite.
- `server.ts` — server Express locale: serve Vite in sviluppo e l'API `/api/translate` (Gemini). Non è usato su Pages.
- `vite.config.ts` — config Vite; `base` cambia con `VITE_PUBLIC=1` (sottocartella `/All-in-one/` per Pages).
- `package.json` / `package-lock.json` — dipendenze e script (`dev`, `build`, `lint`).
- `tsconfig.json` — config TypeScript (`npm run lint` = `tsc --noEmit`).
- `.github/workflows/pages.yml` — build statico e deploy su GitHub Pages a ogni push su `main`.
- `.nojekyll` — file vuoto: dice a GitHub Pages di non usare Jekyll.
- `.gitignore` — esclude dipendenze, build, segreti (`.env`, chiavi) ed file di editor.
- `README.md` — cos'è il progetto, come si avvia, come si pubblica su Pages.
- `CLAUDE.md` — regole per l'AI in questo progetto.
- `decisions.md` — elenco delle scelte importanti.
